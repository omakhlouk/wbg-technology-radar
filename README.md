# WBG Technology & Innovation Radar

A public-source technology and startup landscape for WBG development, ITS capabilities and the wider frontier.

This edition includes **37 trends, 102 startups and ecosystem builders, 17 use cases and 200 source entries**, checked on **23 November 2026**.

## Website

GitHub Pages publishes the files in the root of the `main` branch. In Settings → Pages, the publishing source is **Deploy from a branch**, **main**, **/(root)**. Subsequent commits to the website files update the site automatically. No application server, API key or visitor account is needed.

The radar has WBG, ITS and Frontier perspectives; an animated, expandable radar; source-linked profiles; company comparison; use cases; recent signals; and a local shortlist. Its positions describe editorial assessments rather than WBG adoption. Public-good organizations are labelled separately from commercial companies. This is a curated edition, not an exhaustive or continuously refreshed market map.
